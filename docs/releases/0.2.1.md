# Codevo Whisper 0.2.1

## New features

- Smart dictation mode: tap to keep recording, hold and release to finish. Existing hold and toggle preferences are preserved.
- Combination keyboard shortcuts for dictation.
- Local models stay loaded between dictations.
- Configurable final transcript processing.
- Output methods and clipboard preferences.
- Recording mute and sound feedback.
- Opt-in transcript history.

## Linux — experimental

Linux AppImage and .deb packages are provided for x64 and arm64. X11 supports automatic insertion into verified text fields. Wayland uses clipboard delivery for manual paste; automatic insertion on Wayland is not supported in this release.

- Fixed automatic insertion into Snap applications, including Discord, by running the native input helper through the user's systemd manager.
- Fixed recognition of Chromium/Electron editors and editable sections in Firefox-based browsers, including Zen.
- Dictation waits for shortcut keys to be released before inserting text.
- Onboarding now uses device-neutral text on every platform.

For an existing Linux installation, open **Nastavenia → Prístup k systému → Povoliť rozpoznávanie polí**. This enables desktop-wide accessibility support and persists across sessions. It does not enable the screen reader. A working systemd user manager is required for packaged Linux builds.

Linux support remains experimental. The operator verified the x64 test candidate in T3 Code, Snap Discord and WhatsApp in Zen. Other desktops, arm64 runtime behavior, and additional Wayland cases still need user verification.
