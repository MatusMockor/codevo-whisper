# Stream I - Živý text Implementation Plan

> **For agentic workers:** executed natively by the stream agent (stream rules forbid subagents). Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Live transcript in the macOS app: LocalEngine on `packages/audio` (progressive commits in both overlay modes, partials only in Živý text), RemoteEngine partials, an engine event contract and the Živý text overlay.

**Architecture:** `DictationOptions` gets an event sink `onTranscript(update)`. `LocalEngine` owns one `TranscriptionDispatcher` backed by a `TranscribeCliTranscriber` (`SegmentTranscriber` over `runTranscribeCli`) and starts one `RollingSession` per dictation. `RemoteDictation` forwards `partial`/`final` messages and a `restart` after a reconnect. `DictationSession` feeds the updates into a `LiveTranscript` view model only in Živý text mode and puts `live: { confirmed, tentative }` on the `recording` and `processing` overlay states.

**Tech Stack:** TypeScript, Electron 45, React 19, Vitest 5, Playwright, `@codevo-whisper/audio`, `@codevo-whisper/stt-runner`.

**Spec:** `docs/specs/2026-10-25-codevo-whisper-design.md` 5.3, 5.4, 6; `docs/reports/phase-3-audio-report.md` ("How to wire this into LocalEngine"); `docs/reports/2026-10-26-remote-engine-report.md`; `docs/design/mockup.html` (Živý text tile, `.ov-text`, `.w`, `.w.t`).

## Global Constraints

- Indikátor stays the default; in Indikátor mode no partials are requested or computed (local and remote).
- Every engine call stays <= 25 s of audio (segmenter default `hardMs: 25000`).
- `SegmentTranscriber` must reject promptly on abort and enforce its own per-call timeout (local: 60 s).
- Recordings shorter than 640 bytes are never sent to transcribe-cli (old `MIN_TAIL_BYTES`); empty segment texts are skipped when joining.
- RemoteEngine sends `partials: true` only in Živý text and never `partials: false`; keep the one type assertion for `start.partials`.
- Overlay window stays non-focusable, `showInactive`, never `focus()`.
- No code comments, no `else`, small files, tests use real collaborators; only transcribe-cli (fake script), STT HTTP and the Noise responder may be faked.
- Do not edit `src/main/audio/**` or `e2e/capture.spec.ts` (stream J).

## Review Focus

- A dictation shorter than 20 ms or pure silence must not spawn transcribe-cli and must end with "Nezachytila sa žiadna reč" - test in Task 2.
- A transcribe-cli call that hangs must end the dictation after the call timeout with the text recognised so far kept as last transcript - test in Task 2.
- Cancel (Esc / abandon) during a long dictation must kill the running transcribe-cli and insert nothing - test in Task 2.
- A server reconnect re-sends the whole recording; the overlay must not show the old attempt's text next to the new one - test in Task 3 (`restart` event) and Task 4 (view reset).
- Indikátor mode must never show transcript text even though finals arrive progressively - test in Task 4.
