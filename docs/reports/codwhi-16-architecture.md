# Mobile trust boundaries

The phone records audio only. The paired server runs the transcription model. Shared TypeScript owns the existing Noise client, canonical protocol codecs, pairing approval, session sequencing, final segment assembly, and a bounded audio queue. Native code owns platform privileges and the editor.

The Android IME captures the originating InputConnection and editor generation. A fresh run can consume that lease only after the user explicitly requests Stop, the matching session finishes successfully, and the editor remains active. Commit consumes the lease before calling commitText. Cancel, input restart, unbind, finish, keyboard hide/switch, selection change, lock, and service destruction invalidate it synchronously before asynchronous cleanup. No surrounding text is read. Password input variations and TYPE_NULL fields disable Record.

AudioRecord supplies mono 16 kHz PCM16 little-endian frames of 3200 bytes. Every bridge event has a run id, sequence, and explicit base64 payload. Eight unacknowledged native frames is the limit. JavaScript acknowledges only after validating sequence and appending to a bounded 320000-byte queue. The sender preserves order, respects flow pauses and WebSocket bufferedAmount, and sends at most 3200 bytes every 100 ms. Only the final frame may be below 640 bytes. Overflow, missing frames, timeout, authentication failure, and protocol failure terminate the run. There is no automatic recording replay.

A successful done message alone cannot authorize insertion. The native lease requires explicit Stop. The shared session also requires finish to have been sent. Cancel closes the connection, rejects completion, and prevents delayed done or final callbacks from supplying text.

The application owns ReactHost. VoiceInputService starts and tracks a HeadlessJsTaskContext task without a visible Activity. The JavaScript task registers audio and command listeners before acknowledging native readiness. Its promise stays alive until success, cancel, or failure. The native ready call rejects stale runs. The task permits foreground execution and has a bounded lifetime. Tests force-stop the app before selecting the IME, so the JS engine starts from bundled bytecode without Metro.

The native vault stores an AES-GCM envelope in Android noBackupFilesDir. Android Keystore holds the wrapping key. Temporary file replacement preserves the previous approved envelope on a failed write. iOS uses a device-only Keychain item with atomic update. The Noise identity private key is exportable JavaScript memory during a session. It is not a hardware-held non-exportable identity. Native SecureRandom or SecRandomCopyBytes supplies all randomness; a missing native bridge fails closed. There is no Math.random fallback.

External pairing tokens, encrypted server frames, protected stored data, and native bridge events are parsed at their boundaries. Pinned server keys and Noise authenticate the remote peer. TLS validation remains enabled. Protocol ciphertext uses the existing IKpsk2 pairing and IK session implementation, existing prologues, tagged messages, and independent directional rekeys every 10000 successful messages without nonce reset. No new crypto or server protocol was introduced.

The pairing token and PCM are never logged. Transcript output stays in the editor or foreground recorder. Pairing failure preserves the previous envelope. The Android backup flag is disabled; the iOS Keychain item is not synchronizable or restorable to another device.

Dependency choices are React Native 0.88.1 with React 19.3.0 from its official template; native platform capture and vault APIs instead of microphone/storage plugins; @scure/base for canonical base64 and hex; @stablelib/utf8 for strict portable decoding; and react-native-url-polyfill for WHATWG endpoint parsing in Hermes. Babel, Metro, CLI, Gradle plugin, codegen, and the Hermes compiler are pinned build dependencies. The Hermes compiler version matches the React Native package. Context7 tools were not exposed in this session; vendor documentation, published package contents, and installed source supplied the compatibility evidence.
