## Deviations

- Notarization runs in scripts (`mac.notarize: false`) instead of electron-builder's built-in step, to get the submission ID, an explicit timeout and a status check (spec 10 latency rule).
- CI stages the app with the `zip` target, not `dir`: electron-builder writes `app-update.yml` only when a dmg or zip target is packed. The stage ZIP is discarded; DMG and ZIP come from the stapled app via `--prepackaged`.
- The local build (`dir` target) therefore has no `app-update.yml`; irrelevant until electron-updater is wired.
- Native binaries are signed before packaging and excluded from electron-builder's signing (`signIgnore`), otherwise `@electron/osx-sign` re-signs them with file-name identifiers.
- Intel runner `macos-15-intel` instead of `macos-13` (retired by GitHub in December 2025).
- The spike scripts were ported to TypeScript run by Node 24 type stripping, with extra checks (plain file names, legacy `path` consistency). The CI fuse gate is `verify-fuses.ts`, which reads the expectation from `electronFuses` in `electron-builder.yml` instead of parsing the `electron-fuses read` text output.
- No `rsvg-convert` on the machine; the icon is rendered by a small Node rasterizer instead.
- `.gitignore` gained `!/scripts/release/` (the existing `release/` pattern ignored the new directory).
